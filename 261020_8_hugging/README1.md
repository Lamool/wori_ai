# AI vs 나 빈칸 퀴즈

Hugging Face의 한국어 BERT 모델로 만든 터미널 빈칸 퀴즈 게임입니다.

## 모델

| 항목 | 내용 |
|---|---|
| 모델 | [`klue/bert-base`](https://huggingface.co/klue/bert-base) |
| 작업 | Fill-Mask (빈칸 채우기) |
| 만든 곳 | KLUE (한국어 자연어 이해 연구 프로젝트) |
| 크기 | 약 1억 개 파라미터, 약 400MB |

**어떤 모델인가요?**
한국어 뉴스, 위키백과 등의 문장에서 단어를 가리고 맞히는 연습을 반복해 학습한 BERT 모델입니다. 문장에 `[MASK]`(빈칸)를 넣어 주면, 빈칸의 **앞뒤 문맥을 함께 보고** 들어갈 단어 후보를 확률과 함께 알려 줍니다.

```
입력: 대한민국의 수도는 [MASK]이다.
출력: 서울 (81%), 부산 (4%), 어디 (2%) ...
```

> 모델은 따로 설치할 필요가 없습니다. 처음 실행할 때 Hugging Face에서 자동으로 내려받습니다.

## 실행

```bash
python quiz.py
```

- 처음 실행할 때는 모델(약 400MB)을 내려받느라 몇 분 걸립니다. 이후에는 저장된 모델을 써서 바로 시작됩니다.
- 실행하면 메뉴가 나옵니다.

```
=== 🧠 빈칸 퀴즈 ===
1. 맞히기 모드 (AI vs 나)
2. 속이기 모드 (내가 문제 내기)
3. 종료
선택 :
```

**1. 맞히기 모드**
빈칸 문제가 나오면 들어갈 단어를 입력합니다. 나와 AI가 같은 문제를 풀고 점수를 겨룹니다. 모르면 엔터, 그만하려면 `exit`를 입력합니다.

```
[1/5] 대한민국의 수도는 ____이다.
나의 답 : 서울
```

**2. 속이기 모드**
정답 단어를 `[ ]`로 감싼 문장을 입력하면 AI가 빈칸을 맞힙니다. 내 정답이 AI 후보 2~5위면 성공(2위 3점, 3위 2점, 4~5위 1점), 1위면 실패, 5위 밖이면 무효입니다.

```
문제 : 나는 아침마다 [커피]를 마신다.
```

## 문제 추가

`problems.txt`에 정답을 `[ ]`로 감싸서 한 줄에 한 문제씩 적습니다. `#`으로 시작하는 줄은 무시됩니다.

```
고래 싸움에 [새우] 등 터진다.
태양은 [동쪽]에서 뜬다.
```

## 한계점

- BERT는 빈칸 하나에 토큰(조각) 하나만 채울 수 있어서, `외양간`(`외양` + `##간`)처럼 여러 조각인 단어는 정답으로 쓸 수 없습니다. 이런 문제는 자동으로 제외됩니다.
- 사실을 아는 것이 아니라 확률로 단어를 고르기 때문에 상식 문제를 틀리기도 합니다.
